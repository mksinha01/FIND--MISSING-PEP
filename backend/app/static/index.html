💡 How to Operate the Edge CCTV Monitoring Station

1. Run py -m edge_agent.main in your terminal to launch the Edge Agent desktop GUI.
2. The Edge Agent connects to this central server, downloads registered 512-D ArcFace facial embeddings, and loads them into a thread-safe FAISS vector index.
3. Video streams (webcams, test MP4 files, or RTSP cameras) run through real-time SCRFD detection and ByteTrack tracking at 15 FPS.
4. When a missing person is detected (3 consecutive matches $\ge$ 60%), an instant sighting alert is uploaded and appears live on this dashboard!
