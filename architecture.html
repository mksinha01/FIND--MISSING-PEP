10-Stage Edge AI Pipeline Architecture

Strictly ordered real-time inference workflow running locally on CPU in the PySide6 Edge Agent.

Primary Research Contribution: Spatial-Temporal Verification

Traditional video facial recognition suffers from high false-positive rates (15%–25%) due to motion blur, extreme head pose, and lighting variance on single frames. FIND-MISSING-PEP implements a Temporal Moving Window: face detections are first assigned a persistent ID via ByteTrack. Only tracks maintaining an average ArcFace similarity μ ≥ 0.42 across 5 temporal windows trigger verified sighting alerts, dropping false alerts by over 80%.

01 ~0 ms (I/O)

RTSP Stream Ingestion

OpenCV FFMPEG decoder captures 10–15 FPS video from IP cameras. Auto-reconnect with exponential backoff on network drop.

edge_agent/camera/rtsp_reader.py cv2.VideoCapture
02 <1 ms

Frame Sampling & Buffer

Throttles incoming stream to 1–15 FPS target rate to bound CPU load. Maintains circular RAM buffer for 5s pre-match video clip capture.

edge_agent/camera/frame_sampler.py Circular Deque
03 ~15 ms

SCRFD Face Detector

Lightweight ONNX model (det_10g.onnx, 16 MB). Letterboxes frame to 640×640; outputs bounding boxes and 5 facial landmark coordinates.

edge_agent/ai/face_detector.py ONNX Runtime (CPU)
04 ~1 ms

ByteTrack Object Tracker

Associates detections across consecutive frames using Kalman filter and two-stage IoU matching. Assigns persistent track IDs.

edge_agent/ai/tracker.py lapx / Kalman Filter
05 <0.5 ms

Face Quality Gate

Rejects poor detections: Laplacian blur variance ≥ 100, min face size ≥ 40px, aspect ratio 0.6–1.2, and 5 landmarks enclosed within bbox.

edge_agent/ai/face_quality.py Laplacian Var
06 <1 ms

5-Point Affine Alignment

Transforms face crop using standard Umeyama affine warp onto canonical 112×112 coordinate space based on eyes, nose, and mouth corners.

edge_agent/ai/face_aligner.py 112×112 Aligned Crop
07 ~8 ms

ArcFace 512-D Embedder

Deep ResNet-50 feature extractor (w600k_r50.onnx, 166 MB). Generates L2-normalized 512-dimensional float32 biometric feature vector.

edge_agent/ai/face_recognizer.py 512-D L2-Norm
08 <0.2 ms

FAISS Vector Search

In-memory exact inner-product (cosine) search against all active missing person embeddings. Filters candidates with score ≥ 0.30.

edge_agent/ai/vector_search.py FAISS IndexFlatIP
09 Research Core

Temporal Verifier

Accumulates matching history for (track_id, person_id). Triggers sighting only if mean score across 5 frames ≥ 0.42 with 300s cooldown.

edge_agent/ai/temporal_verifier.py Sliding Window Average
10 Async

Evidence & Alert Dispatch

Saves 112×112 face crop, annotated full frame, and circular clip. Emits Qt alert, stores in SQLite offline queue, and uploads via HTTP.

edge_agent/ai/evidence_collector.py Multipart HTTP + SSE

End-to-End System Sequence Flows

Interactive execution traces covering report creation, background sync, CCTV alert dispatch, and offline recovery.

1
Citizen Photo Upload & Metadata Submission Web/Android ➔ FastAPI

User selects 1–4 photos of the missing person. Web app compresses images via Canvas (<1 MB). Sends multipart request with metadata (name, age, last-seen location).

POST /api/reports/ HTTP/1.1 Content-Type: multipart/form-data; boundary=----WebKitFormBoundary [ReportCreate JSON payload + 3 compressed JPEG photos]
2
Server-Side Face Detection & Crop Alignment FastAPI ➔ SCRFD ONNX

Backend loads photos into OpenCV, runs SCRFD detection. Selects largest face, checks quality score, aligns 5 landmarks to 112×112 canonical crop, and saves to uploads/faces/.

# backend/app/services/face_processing.py aligned_face = aligner.align(img, landmarks) cv2.imwrite("uploads/faces/{photo_id}.jpg", aligned_face)
3
ArcFace 512-D Embedding Extraction & DB Storage FastAPI ➔ PostgreSQL

Processes aligned crop through ArcFace (w600k_r50.onnx). Extracts 512-D float32 vector, L2-normalizes, and stores as 2048-byte binary blob in PostgreSQL. Updates report status to ACTIVE.

INSERT INTO face_embeddings (person_id, photo_id, embedding, quality_score) VALUES ($1, $2, $3::bytea, $4); UPDATE missing_persons SET status = 'ACTIVE' WHERE id = $1;
4
Redis Pub/Sub Event Broadcast FastAPI ➔ Redis Pub/Sub

Backend publishes report_status_change event to Redis channel. Connected Web clients and Edge Agents receive real-time notification to invalidate local embedding cache.

1
Periodic Incremental Sync Request Edge Agent ➔ FastAPI

Every 60s, Edge Agent queries central backend with its device API key and the timestamp of its last successful sync (since=ISO_TIMESTAMP).

GET /api/embeddings/sync?since=2026-10-13T12:00:00Z HTTP/1.1 X-API-Key: agent-sha256-key-token
2
Zero-Copy Binary Vector Packing FastAPI Serialization

Instead of slow JSON serialization (6 KB/person), backend streams embeddings as raw float32 bytes (2048 bytes/vector) with person UUID mapping list.

3
Thread-Safe Atomic FAISS Swap Edge Agent Vector Store

Edge Agent builds a new FAISS IndexFlatIP index in the background worker thread. When complete, atomically swaps the pointer without pausing ongoing CCTV camera streams.

# edge_agent/storage/faiss_store.py new_index = faiss.IndexFlatIP(512) new_index.add(np.ascontiguousarray(embedding_matrix)) with self.lock: self.active_index = new_index # Atomic pointer swap
1
CCTV Recognition & Temporal Score Verification Edge Agent Camera Thread

Track #42 matches Person #102 across 5 consecutive frames with similarities [0.61, 0.64, 0.65, 0.62, 0.66]. Mean score = 0.636 ≥ 0.42 threshold. Sighting confirmed!

2
Evidence Capture & Local Storage Edge Agent Evidence Collector

Captures 112×112 cropped face, 1920×1080 full frame with bounding box, and extracts 5s circular video buffer clip. Writes to local disk and creates pending record in SQLite.

3
Multipart Evidence Upload to Backend Edge Agent ➔ FastAPI

Edge Agent calls POST /api/sightings/ with camera ID, GPS coordinates, timestamp, similarity score, and multipart JPEG files.

4
Multi-Channel Push: SSE + FCM FastAPI ➔ Web / Android Clients

Backend sends high-priority FCM push notification to family member's phone (rings in background) and broadcasts SSE event to all connected Web Command Centers.

1
Network Drop / Backend Offline Edge Agent Network Layer

When internet connection drops or central server restarts, Edge Agent catches httpx.ConnectError. Pipeline execution continues uninterrupted.

2
Local SQLite Queue Staging Edge Agent local_data.db

Sighting event, evidence paths, and verification timestamps are saved to offline_sightings table in local SQLite database with status QUEUED.

3
Health Recovery & Auto-Drain Worker Edge Agent Background Worker

Background worker pings GET /health with exponential backoff. Upon 200 OK, drains queued sightings in chronological order and clears local queue.

REST Endpoints & Communication Protocols

Complete REST contract, Server-Sent Events stream, and Edge Agent binary sync specification.

GET /api/embeddings/sync
Edge Agent Biometric Synchronization Endpoint

Retrieves missing person face embeddings as high-efficiency binary packets. Supports full sync or incremental sync via since query parameter.

Headers: X-API-Key: <edge_agent_api_key> Query: ?since=2026-10-13T12:00:00Z (Optional ISO timestamp) Response (200 OK JSON with Binary Base64/Raw Array): { "full_sync": false, "sync_timestamp": "2026-10-13T12:45:00Z", "persons": [ { "person_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6", "full_name": "Rohan Sharma", "embeddings": ["<base64_encoded_512_float32_bytes>"], "photo_url": "/uploads/faces/face_1.jpg" } ], "removed_ids": [] }
POST /api/sightings/
Edge CCTV Sighting Submission (Evidence Upload)

Dispatched by Edge Agent when temporal verification criteria are met. Uploads cropped face, full frame, and telemetry metadata.

Headers: X-API-Key: <edge_agent_api_key>, Content-Type: multipart/form-data Form Fields: person_id: "3fa85f64-5717-4562-b3fc-2c963f66afa6" camera_id: "8c7a6e12-32b1-4190-b981-d1f86c234a91" similarity_score: 0.642 timestamp: "2026-10-13T12:48:22Z" crop_image: [binary JPEG, 112×112] frame_image: [binary JPEG, 1920×1080]
GET /api/events/stream
Server-Sent Events (SSE) Real-Time Notification Stream

Long-lived HTTP streaming connection consumed by Web Portal and Edge GUI. Pushes instant sightings and heartbeat ping every 30s.

Event Schema: event: new_sighting data: {"sighting_id": "...", "person_id": "...", "full_name": "...", "similarity": 0.642, "camera_name": "North Gate", "timestamp": "..."} event: ping data: {"timestamp": 1791884400}
POST /api/reports/
Citizen Missing Person Report Creation

Atomic creation of missing person dossier with photos. Triggers server-side SCRFD alignment and ArcFace embedding generation.
